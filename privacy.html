Privacy Policy

Last updated: November 5, 2026

Slop Dashboard is a personal tool used only by its owner to view statistics for the owner's own social media accounts.

What data it accesses

With the account owner's permission (read-only), it reads channel and account details (name, ID, follower or subscriber count) and per-video statistics (views, likes) from YouTube (via YouTube API Services), Facebook, Instagram and TikTok.

How data is used and stored

Data is used only to display statistics in a dashboard. It is stored only on the owner's own computer. It is not sold, shared with, or sent to any third party, and it is not used for advertising.

YouTube

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy. You can revoke access at any time at Google security settings.

Deleting data

Removing an account in the tool deletes all of its stored data from the computer. Revoking access through the platform's settings also stops all data access, and stored data for that account is deleted within 7 days.
